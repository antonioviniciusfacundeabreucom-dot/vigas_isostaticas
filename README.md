# Página Web que calcula dados de estruturas de vigas isostáticas


  O projeto consiste em auxiliar engenheiros civis e arquitetos a otimizar cálculos de vigas com duas forças e dois suporte, porém o profissional da construção civil necessita
interpretar o resultados e do dimensionamento da viga. Além disso, foi utilizado tecnologias da web como linguagens de marcação html, css e linguagem interpretada como JavaScript
e deve-se ser adicionado futuramente gráficos do momento fletor e da cortante.
# Execução da página 
  Vai ser adicionado em breve um link para acesso do cálculo e do gráfico.
  
## Créditos
Esse cálculo nos vídeos do Canal da Engenharia para cálculo de vigas.

#### Propósito Educacional

  O começo da página web será usado em cursos de alunos de engenharia sempre priorizando o cálculo feito a mão e a transição para as tecnologias atuais.
